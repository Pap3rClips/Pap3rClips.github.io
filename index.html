LLM Red Team Bench

IA, Cybersécurité

Un banc de tests offensifs aligné sur l'OWASP Top 10 for LLM Applications. Il rejoue un catalogue d'attaques contre une application d'IA et mesure leur réussite par des détecteurs déterministes, sans recourir à un modèle comme juge. La même application est évaluée en version vulnérable et en version durcie, pour isoler l'apport de chaque défense.

Taux de réussite des attaques : 100 % sur l'application vulnérable, 0 % après durcissement.

Python, OWASP LLM Top 10, injection de prompt, pytest, intégration continue.

Wazuh LLM Triage

IA, Cybersécurité, Réseau & systèmes

Un outil qui regroupe les alertes Wazuh en incidents, établit des faits fiables sans intelligence artificielle, puis demande à un modèle un résumé et des actions recommandées. Le modèle conseille mais ne décide jamais seul : des garde-fous l'empêchent de sous-estimer la gravité, et le système résiste aux instructions malveillantes cachées dans les alertes.

Soixante-dix alertes regroupées en huit incidents priorisés.

Python, Wazuh, Sysmon, API Claude, recherche BM25, pytest, intégration continue.

Code source

LLM Privacy Gateway

IA, Cybersécurité, DevOps & cloud

Une passerelle qui remplace les données personnelles par des pseudonymes avant d'interroger une API de LLM, puis reconstitue la réponse. Le fournisseur du modèle ne voit jamais la donnée réelle, tandis que l'utilisateur reçoit une réponse complète. Les tables de correspondance sont chiffrées au repos en AES-256-GCM.

Python, FastAPI, AES-256-GCM, Docker, conformité RGPD.
